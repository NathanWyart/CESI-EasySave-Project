# EasySave - Logiciel de Sauvegarde

## Présentation du projet

**EasySave** est une application console développée en **C# / .NET 8.0** dans le cadre d’un projet mené par l'équipe de développement de **ProSoft**. Le logiciel a pour objectif de fournir un outil de sauvegarde personnalisable et simple d’utilisation, tout en respectant les standards de qualité et de maintenabilité exigés par l’entreprise.

## Fonctionnalités principales

- Création jusqu’à 5 travaux de sauvegarde
- Sauvegarde en mode complet ou différentiel
- Exécution manuelle ou automatisée des sauvegardes
- Multilingue (français / anglais)
- Journalisation en JSON (traces des opérations)
- Chargement et persistance des sauvegardes
- Interface console ergonomique
